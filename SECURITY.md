# Security policy

## Supported versions

Security fixes are provided for the latest published release. The current repository is preparing the 1.1.0 maintenance release; the historical 1.0.3 Bintray artifact is no longer distributed.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's **Report a vulnerability** private reporting feature for this repository. Include affected versions, reproduction steps, impact, and any suggested mitigation.

Maintainers will acknowledge a complete report when available, coordinate a fix and disclosure, and credit reporters who want public attribution.
